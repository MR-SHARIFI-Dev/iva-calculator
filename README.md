این پروژه فقط یک ماشین حساب ساده نیست؛ بلکه شامل:

# ✨ Features

## 🧠 Advanced Calculation Engine

موتور محاسبات IVA بدون استفاده از `eval()` ساخته شده است.

ویژگی‌ها:

✅ Custom Expression Parser
✅ AST Architecture
✅ Operator Priority
✅ Nested Parentheses
✅ Error Handling

پشتیبانی:

* Addition `+`
* Subtraction `-`
* Multiplication `*`
* Division `/`
* Power `^`
* Parentheses `( )`

# 📦 Installation

## Clone Repository

```bash
git clone https://github.com/MR-SHARIFI-Dev/iva-calculator.git
```

Enter project:

```bash
cd iva-calculator
```

Run:

```bash
open index.html
```

یا از یک Static Server استفاده کنید:

```bash
npm install
npm run dev
```
