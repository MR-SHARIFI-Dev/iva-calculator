# IVA Calculator Pro v3.1.0

## Fixes and improvements

- Increased arithmetic-operator contrast in both dark and light themes.
- Prevented stacked binary operators; selecting a second operator replaces the previous one.
- Made `=` finalize the calculation, collapse the expression to its result and save the original expression in history.
- Automatically closes valid open function parentheses when `=` is pressed.
- Added smarter decimal, parenthesis, postfix and backspace input rules.
- Corrected DEG/RAD boundaries, exact-value cleanup and undefined tangent handling.
- Improved theme initialization, labels, persistence and stale service-worker behavior.
- Restored `Ans` from the newest saved history entry after reloading.
- Expanded automated coverage to 12 test groups, including every exposed scientific operation and realistic button sequences.
