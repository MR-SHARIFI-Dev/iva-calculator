# IVA Calculator Pro v3.3.1

## ✨ New

- **Luxury Gold & Black theme.** The entire interface has been redesigned around a premium gold-on-black palette: deep black surfaces with warm gold glows, gold-gradient operator and equals keys, gold result and brand typography, and matching dark + light variants. The light theme is a soft cream/gold companion so the app stays readable everywhere.
- **New icon set.** The app icon, favicon, apple-touch icon, banner, poster and social preview now all use the uploaded IVA emblem artwork. Brand images are shipped as raster PNGs (`assets/logo.png`, `assets/favicon.png`, `assets/apple-touch-icon.png`); the manifest exposes 64 / 192 / 512 px icons with `any maskable` support.
- **Version bumped to 3.3.1** across the HTML, service worker, manifest, package metadata, scripts and tests (cache key upgraded so installed PWAs refresh automatically).

## 🔧 Maintenance

- Service worker asset manifest updated to the new PNG icon set (SVG logos removed).
- Meta theme colors updated to the gold/black palette for both themes.

## Tests

- All 23 Node tests and 8 Chromium interaction tests still pass against the new theme and assets (version assertions now check `v3.3.1`).
