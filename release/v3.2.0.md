# IVA Calculator Pro v3.2.0

## Input hardening and cache fix

- Binary operators are now strictly ignored while another binary operator is pending.
- Arithmetic operator buttons become visibly disabled until an operand is entered.
- Held keyboard keys are ignored through `KeyboardEvent.repeat` protection.
- Expressions are capped at 500 characters at the input boundary.
- Added stress tests with 10,000 repeated presses per operator and 50,000 mixed presses.
- Added a visible version label to make stale deployments immediately detectable.
- Reworked the service-worker upgrade path using unique asset URLs, `skipWaiting`, awaited `clients.claim`, old-cache removal and one-time navigation to the current version.
- Added ESLint 10 static/security checks and Playwright browser automation.
- Verified 1,000 real keyboard operator attempts in Chromium, `=` finalization, light-theme visibility and persistence.
- Kept the browser runtime dependency-free and retained the safe recursive-descent parser.
