# IVA Calculator Pro v3.3.0

## Bug fixes

- **Euler vs scientific notation conflict fixed.** The `e` key now always means Euler's number: `2e3` is 2 × e × 3 ≈ 16.31. Scientific notation uses an uppercase `E` (`2E3` = 2000, `2E-3` = 0.002). Previously pressing `2`, `e`, `3` silently produced 2000.
- **Negative exponents are now reachable.** `2^-2` can be entered with the minus button or the keyboard; the minus key is enabled after `^` and after `(`.
- **No more silent implicit multiplication after postfix operators.** A digit, constant or parenthesis pressed right after `!` or `%` is ignored (pressing `5`, `x!`, `3` no longer yields a confusing 360); an explicit operator is required.
- **Space no longer duplicates a focused key.** The Space key no longer re-activates the last clicked button.
- **Formatted scientific results survive continuation.** Huge/tiny results are displayed as `1E+21` and can be extended (`+ 1`) without corrupting the expression or display.
- **Crash-proof storage.** Every `localStorage` access is guarded, so the calculator keeps working in sandboxed iframes, private browsing and other environments that deny storage.
- **History entries are validated** when read from storage; corrupt or old-format entries are dropped instead of crashing the UI.
- **Fixed the `2pi` display** (was rendered `2pi`, now `2π`) and tightened unary minus / exponent spacing in the expression view.
- **Keyboard hardening.** All handled keys prevent browser default behavior (no Firefox quick-find on `/`), and `×`, `÷`, `−` keys are accepted as `*`, `/`, `-`.
- **"New expression" detection now covers every function.** Scientific function names (`asin`, `abs`, `exp`, `floor`, …) correctly start a fresh expression after `=`.
- **Guarded decimals in scientific notation** (`2E3.` is rejected instead of producing a dead preview).

## Tests

- 23 Node tests: parser, input rules, formatting round-trips, release checks.
- 8 real Chromium interaction tests, including regression tests for every bug above.
- Added `scripts/` user-session simulations that drive the app like a person (trigonometry, errors, history, reloads, denied storage, mobile viewport) — all green.
